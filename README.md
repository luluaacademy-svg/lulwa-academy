# 🐚 أكاديمية لؤلؤة — صفحة تعريفية

صفحة عربية (RTL) بثيم **اللؤلؤ** بألوان الباستيل البنفسجي والوردي، تحتوي على كل روابط الأكاديمية.

## ▶️ طريقة العرض

**الطريقة الأسهل (محليًا):**

```bash
node server.js
```

ثم افتح المتصفح على: **http://localhost:8787**

أو بمجرد النقر المزدوج على `index.html` ستُفتح الصفحة مباشرة (تعمل بدون خادم أيضًا).

---

## ✏️ الروابط التي يجب تعديلها

افتح الملف `index.html` واستبدل الروابط التالية بروابطك الحقيقية:

| المكان في الصفحة | ابحث عن | استبدل بـ |
|---|---|---|
| زر التسجيل | `https://forms.gle/your-registration-link` | رابط نموذج التسجيل |
| واتساب (البطاقة + الزر العائم) | `https://wa.me/00000000000` | `https://wa.me/` + رقمك الدولي |
| تيليجرام | `https://t.me/your_channel` | رابط قناتك |
| إنستغرام | `https://instagram.com/your_account` | رابط حسابك |
| البريد الإلكتروني | `mailto:hello@lulwa-academy.com` | بريدك |

## ✏️ تعديل المحتوى

- **الإحصائيات** (أونلاين / مجالات / دورات): في قسم `<ul class="stats">`.
- **المجالات والدورات**: قسم `<div class="fields">` (قابلات تفتح عند الضغط) — العلوم الشرعية، التعليم الإبداعي والفني، التكوين المهني (قريبًا).
- **صفحة تفاصيل الدورة**: `course.html?id=المفتاح` — تُعرض من ملف البيانات `assets/js/courses.js` (الوصف، ما ستتعلمينه، معلومات الدورة، زر التسجيل). الدورات المجانية بادجها أخضر «مجانية»، والمدفوعة بنفسجي «مدفوعة».
- **الأيقونات**: رسومات SVG مرسومة يدويًا ومضمّنة داخل `index.html` (بلا إيموجي)، بلون تدرّج بنفسجي–وردي.
- **النصوص التعريفية**: فقرة `tagline` و`intro` في الواجهة.

> 💡 قسم «آراء الطالبات» محذوف حاليًا لأن الأكاديمية جديدة، وتنسيقاته ما زالت جاهزة في `style.css` — فإذا جمعتِ آراء لاحقًا أعيدي القسم بكل سهولة.

## 🎨 الألوان

كل الألوان في أعلى ملف `assets/css/style.css` تحت `:root`:

| المتغير | اللون |
|---|---|
| `--violet-500` / `--violet-600` | البنفسجي الأساسي |
| `--pink-500` / `--pink-600` | الوردي الأساسي |
| `--pearl-1` / `--pearl-2` | خلفية اللؤلؤ |

## 🖼️ الصور

- `assets/img/logo.webp` (90KB) — الشعار الأساسي المستخدم في الصفحة.
- `assets/img/logo.png` (611KB) — نسخة احتياطية بنفس المقاس.
- `assets/img/favicon.png` — أيقونة التبويب.

لتبديل الشعار: اضغط على الملف بالزر الأيمن → **Set as...** أو بدّل الملف مباشرة بنفس الاسم.

## 📱 المميزات

- تصميم عربي RTL متجاوب مع الجوال والكمبيوتر.
- حركات لطيفة: توهج اللؤلؤ، لمعان العنوان، ظهور العناصر عند التمرير.
- زر واتساب عائم دائم الظهور.
- يدعم `prefers-reduced-motion` لمن يريد تقليل الحركة.
- تدقيق Lighthouse: **100** في الوصول وSEO وأفضل الممارسات.
